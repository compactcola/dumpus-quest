# dumpus-quest

This is a solo project.

I didn't use any tutorials or demos for the game, all assets were made by me. I did use some AI since any google search results in very specific AI overview responses, but otherwise all of the code was done by me or found online in Godot documentation or stack overflow troubleshooting posts.

Right now the game has 1 main loop, and 3 smaller loops:

Main Loop: Survive waves against increasing enemies to defend your home. The enemies double every wave, and when your house's health depletes you lose the game.

Smaller Loops: 1) Player stamina. It's a teeny bit buggy right now, but the player can sprint to get to the other side quicker, but runs out of stamina very fast and must wait 1 second before it recharges. 2) Upgrades. Every round the player can choose from 3 statistical upgrades. In the future I want them to be more interesting and less quantitative (new attacks, double jumps, etc), but right now they do work. 3) Currency. The only real sink and faucet in the game right now. When you kill an enemy you get 5 'beans', which you can spend at the end of every round to repair your house. The cost doubles every time you do it. 

Moving forward in this class I'd like to keep working on this game when applicable. There's a lot of features I just don't have time to add before this assignment is due but I'd like to explore more challenging and fun gameplay elements. More varied enemy types, new and different spells (there is a homing missile spell but I couldn't get it to work properly so it's not useable yet), upgrading the house itself with new abilities, etc.

I'd also like to add more juice to the game of course, but since I want to make my own assets for it, this will take a lot of time and was not feasible for this first assignment.
